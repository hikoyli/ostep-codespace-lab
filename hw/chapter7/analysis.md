## 问题1：SJF 和 FIFO（长度200）
- **FIFO 结果**：平均响应时间 = 200.00，平均周转时间 = 400.00。
- **SJF 结果**：平均响应时间 = 200.00，平均周转时间 = 400.00。
- **分析**：因为所有作业长度相同，所以 FIFO 和 SJF 结果完全一样，不存在护航效应。
## 问题2：FIFO 和 SJF（长度100, 200, 300）
- **FIFO 结果**：平均响应时间 = 133.33，平均周转时间 = 333.33。
- **SJF 结果**：平均响应时间 = 133.33，平均周转时间 = 333.33。
- **分析**：SJF 表现的更好（周转时间更短，仅为333.33），因为 FIFO 会让短作业排在长作业后面死等（护航效应），而 SJF 优先处理短作业，大大减少了整体等待时间。
## 问题3：RR 调度（时间片=1）
- **RR 结果**：平均响应时间 = 1.00，平均周转时间 = 465.67。
- **分析**：RR 的平均响应时间极小（仅为1.00），因为它让所有作业轮流运行，大家都很快获得第一次执行机会。但因为频繁切换，所有作业完成的时间拉长，导致平均周转时间很差（465.67）。
## 问题4：什么工作负载下 SJF 提供与 FIFO 相同的周转时间？
答：当所有作业的长度完全相同时（比如都是200），SJF 和 FIFO 的周转时间一样。
## 问题5：什么工作负载和量子长度下 SJF 提供与 RR 相同的响应时间？
答：当只有一个作业时，或者当RR的时间片（量子长度）设置得非常大（比如1000）时，SJF 和 RR 的响应时间相同。此时 RR 退化为 FIFO。
## 问题6：随着工作长度的增加，SJF 的响应时间会怎样？
答：SJF 是非抢占式的。如果排在最前面的工作非常长，排在后面的短工作就必须等待很久才能获得第一次运行机会，导致响应时间变长。这就是“护航效应”（convoy effect）。
## 问题7：随着量子长度的增加，RR 的响应时间会怎样？写出最坏情况的响应时间方程。
答：随着量子长度的增加，RR 的平均响应时间会变长。
最坏情况下的响应时间方程为：(N - 1) * q 
（其中 N 是作业的数量，q 是时间片/量子长度）。
